            更喜欢用 API 或手工配置？（点开）
            

                
本页所有操作都是普通 HTTP（默认本机即可写入）：

                
curl -X POST   http://127.0.0.1:3000/api/setup/system          -H "Content-Type: application/json" -d '{"name":"a4h",…}'
curl           http://127.0.0.1:3000/api/setup/system/a4h      # 读单个系统（密码掩码不回显）
curl -X PUT    http://127.0.0.1:3000/api/setup/system/a4h      -H "Content-Type: application/json" -d '{"passwd":"新密码"}'   # 半更新
curl -X DELETE http://127.0.0.1:3000/api/setup/system/a4h      # 删除（最后一个系统需 ?force=true）
curl -X PUT    http://127.0.0.1:3000/api/setup/default         -H "Content-Type: application/json" -d '{"name":"a4h"}'     # 切默认

                
也可以手工编辑 sap_systems.toml 后重启网关。
