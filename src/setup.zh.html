首次配置引导

网关已在本地运行，但还没有配置任何 SAP 系统。把下面这段话交给你的 AI 助手，它会引导你完成剩下的配置——大约需要回答 5 个问题。

① 复制这段话，发给你的 AI 助手


        
适用于本机运行的 AI 助手（Claude Code / Cursor / Copilot CLI 等）。内容已自动填入本网关地址。

    


    
    

        
② 接下来会发生什么

        
    
            
  1. AI 助手向网关询问需要哪些字段，然后向你提问：SAP 服务器地址、系统号、客户端、账号、密码，以及一个简短的系统名。
    2. 
            
  2. 它把信息提交给网关——网关会先真实试连一次，连不上不会保存，你不会得到一个坏配置。
    3. 
            
  3. 试连通过后配置立即生效（无需重启），本页面会自动变成绿色。
    4. 
        

        
提示：密码支持 ${环境变量名} 引用形式，让密文留在环境变量里、不进入对话记录。

    


    
    

        

            不想用 AI？手工配置（点击展开）
            

                
在网关运行目录创建 sap_systems.toml（模板见 sap_systems.toml.example）：

                
[systems.a4h]
ashost  = "你的SAP服务器地址"
sysnr   = "00"
client  = "001"
user    = "账号"
passwd  = "密码"
default = true

                
保存后重启网关即可。或者直接 curl 一行完成（网关会先试连再落盘）：

                
curl -X POST http://127.0.0.1:3000/api/setup/system \
  -H "Content-Type: application/json" \
  -d '{"name":"a4h","ashost":"主机","sysnr":"00","client":"001","user":"账号","passwd":"密码"}'

            

        

    


    
    

        

            
            
配置完成，网关已就绪
