terminal 连通测试 

curl -X POST {{BASE_URL}}/api/rfc \
  -H "Content-Type: application/json" \
  -d '{"func_name":"STFC_CONNECTION","inputs":{"REQUTEXT":"hi"},"string_outputs":{"ECHOTEXT":255,"RESPTEXT":255}}'

返回 ECHOTEXT 回显输入、RESPTEXT 带 SAP 系统信息

memory 面向 AI 的元数据 API

  • GET /api/functions/{name} 查函数接口
  • POST /api/functions/search 搜索函数模块
  • GET /api/functions/{name}/doc 查函数文档
  • GET /api/functions/{name}/source 读函数源码
  • GET /api/programs/{name}/source 读程序源码
  • POST /api/table/read 读透明表数据
  • GET /api/ddic/type/{name} 查 DDIC 结构
  • GET /api/ddic/field/{table}/{field} 查字段语义
  • GET /api/dumps 列 ABAP 短转储
  • GET /api/dumps/grouped 什么在反复失败
  • GET /api/dumps/{key}/detail 转储调用栈/出错行
  • PUT /api/objects/{type}/{name}/source 写源码（锁→写→激活）
  • POST /api/objects/{type}/{name}/replace AI 式查找替换编辑

api 通用调用

POST /api/rfc 通用 RFC 调用
ANY /api/adt/{path} ADT REST 透传代理

支持请求体 timeout_secs per-request 覆盖超时

list 其他端点

/ /agents.md /health /ready

/health 为存活探针（不触碰 SAP），/ready 为就绪探针（调 RFC_PING）
