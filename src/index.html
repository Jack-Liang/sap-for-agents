memory AI-facing Metadata API

  • GET /api/functions/{name} Inspect interface
  • POST /api/functions/search Search function modules
  • GET /api/functions/{name}/doc Read function docs
  • GET /api/functions/{name}/source Read function source
  • GET /api/programs/{name}/source Read program source
  • POST /api/table/read Read transparent table
  • GET /api/ddic/type/{name} Inspect DDIC structure
  • GET /api/ddic/field/{table}/{field} Inspect field semantics
  • GET /api/dumps List ABAP short dumps
  • GET /api/dumps/grouped What keeps failing
  • GET /api/dumps/{key}/detail Dump stack / failing line
  • PUT /api/objects/{type}/{name}/source Write source (lock→activate)
  • POST /api/objects/{type}/{name}/replace AI-style find-and-replace

api General Invocation

GET /openapi.json OpenAPI spec (public)

Supports per-request timeout override via timeout_secs in the body
