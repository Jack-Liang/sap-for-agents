Guided Setup

The gateway is running locally but no SAP system is configured yet. Hand the message below to your AI assistant — it will walk you through the rest (about five questions).

① Copy this and send it to your AI assistant


        
For AI assistants running on this machine (Claude Code / Cursor / Copilot CLI, …). The gateway address is filled in automatically.

    


    
    

        
② What happens next

        
    
            
  1. Your assistant asks the gateway which fields are needed, then interviews you: SAP host, system number, client, user, password, and a short system name.
    2. 
            
  2. It submits them to the gateway — which opens a real test connection first. Nothing is saved if the connection fails, so you never end up with a broken config.
    3. 
            
  3. Once the test passes the system is live without a restart, and this page turns green automatically.
    4. 
        

        
Tip: passwords accept a ${ENV_VAR} indirection, keeping the secret in your environment and out of the chat log.

    


    
    

        

            Prefer doing it by hand? (click to expand)
            

                
Create sap_systems.toml next to the gateway binary (template: sap_systems.toml.example):

                
[systems.a4h]
ashost  = "your-sap-host"
sysnr   = "00"
client  = "001"
user    = "account"
passwd  = "password"
default = true

                
Restart the gateway afterwards. Or do it in one curl (the gateway test-connects before persisting):

                
curl -X POST http://127.0.0.1:3000/api/setup/system \
  -H "Content-Type: application/json" \
  -d '{"name":"a4h","ashost":"host","sysnr":"00","client":"001","user":"user","passwd":"password"}'

            

        

    


    
    

        

            
            
Setup complete — gateway is ready
